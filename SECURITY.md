# Segurança e divulgação responsável

- Nunca comite senhas Wi-Fi, senhas Firebase, tokens Telegram, chaves privadas ou arquivos locais de credenciais.
- Os valores Firebase web são marcadores de exemplo neste repositório. Não os substitua pelos valores do seu projeto em uma cópia pública sem revisar as regras e restrições.
- Realtime Database rules e credenciais administrativas não estão incluídas.
- Revogue tokens que tenham sido expostos anteriormente. Remover um segredo do arquivo atual não remove cópias em commits antigos ou em outros locais.
- Antes de fazer deploy, teste com dados fictícios e verifique que acesso não autorizado é negado.
